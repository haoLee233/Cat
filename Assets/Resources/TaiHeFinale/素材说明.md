# 太和殿终章场景素材

本目录的三幅背景与三件构件图由本项目在 2026-10-15 使用内置 imagegen 生成，供游戏内原创关卡使用；没有嵌入网上照片。猫跑动图是项目现有 `Assets/Art/WuMen/跑动1.png` 至 `跑动3.png` 的关卡内副本。

生成意图：

- 前庭台基：故宫太和殿的石质丹陛与连续斜坡，前景须有可行走石地，色彩克制。
- 檐下修缮架：有立柱支撑的两层木架和真实梯口，前景保留完整可行走石地。
- 正殿内景：中央御座台阶、两侧修缮架与殿内金砖地面。
- 复色构件：台基石雕、檐下斗拱彩绘、御座龙纹面板，透明背景、各占图像宽度三分之一。

对应路径在 `TaiHeFinale.cs` 的 `Ground`、`eaves`、`hall` 与 `Climb` 中定义。背景里其余透视木板是远景，不是可站的碰撞面。

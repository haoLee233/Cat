# 锦檐猫影：筑梦人（重制测试版）

使用团结 1.8.4 的新工程。当前只完成封面、故宫地图、午门追逐和保和殿水管关卡，供第一轮试玩；其他关卡尚未制作。

## 打开与试玩

- 工程目录：`E:\锦檐猫影的一切\锦檐猫影_重制开发`
- 团结编辑器中打开 `Assets/Scenes/封面.unity`，按 Play；也可运行 `Builds/Windows/锦檐猫影：筑梦人.exe`。
- 封面点击“点击开始旅程”，在地图中选择午门或保和殿。两关目前都可直接进入，方便测试。
- 午门：进入后播放第一段 CG，可点右上角“跳过片头”，随后显示任务提示。空格、↑ 或鼠标左键二段跳，↓ 切换原版下蹲图片；按顺序收集三只脊兽，避开石狮和上方宫灯。右上角圆形按钮打开设置页，面板右上角叉号可关闭；“退出游戏”返回地图。
- 保和殿：点击管道图片，每次顺时针旋转 90 度；五分钟内将 25 块图片复原成完整水路图。可返回地图或在结算后重试。
- 通关记录保存在本机 PlayerPrefs。

## 工程说明

- `Assets/Art`：从已有素材整理的图片，包括封面、地图、午门和保和殿拼图。
- `Assets/Videos`：原素材视频；午门已接入 `Scene_one_video.m4v`，其余视频暂未接入。
- `Assets/Scripts`：重写的场景切换及两关玩法代码；原“源代码”目录仅供参考。
- `Assets/Editor/RebuildScenes.cs`：生成这四个场景的编辑器脚本；菜单为“锦檐猫影/生成首批场景”。
- `Assets/Editor/WindowsBuild.cs`：检查场景引用并生成 Windows 测试版。

## 当前试玩重点

请优先确认封面、地图、午门、保和殿在你的电脑上的画面位置、大小、点击、关卡完成与返回流程。保和殿当前采用原有 25 张拼图素材，但玩法逻辑是新实现，尚未按发行版逐项还原。
